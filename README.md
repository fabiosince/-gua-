# Água Condomínio V2.9

## Regra de sequência mensal
A leitura atual de um mês passa automaticamente a ser a leitura anterior do mês seguinte.

Exemplo:
- AGO: 100 m³
- SET: 150 m³ → consumo 50 m³
- OUT: 175 m³ → consumo 25 m³

O relatório mensal mostra somente o período selecionado: unidade, leitura anterior, leitura atual, consumo e situação.

## Alertas
O consumo é comparado com até 3 períodos anteriores da própria unidade. Variação de 50% ou mais: atenção; 100% ou mais: verificar. O alerta indica possível consumo excessivo e não confirma vazamento.

## Dados
As leituras permanecem no armazenamento local do aparelho. Não há login ou sincronização em nuvem.
